# 城市置業王

原創繁體中文置業棋盤遊戲。支援 2–4 位玩家、真人與電腦混合、同機輪流、快速及經典模式。本機自動存檔，無帳戶、後端或外部 AI API。

遊玩：https://porscheyeung.github.io/city-property-king/

## 玩法

每位玩家由起點出發，持有 1,500 城市幣。擲兩顆骰子順時針走，買下無主土地、向訪客收租。放棄原價購買即公開拍賣，所有未破產玩家均可參加。每次至少加價 10，退出後不可重新加入。

集齊同色三塊且均未抵押，未建造租金加倍，也可建造三級物業。同組建築最高與最低相差不可超過 1，出售按建造費半價回收。車站不可建造；持有一個未抵押車站租金 25，兩個都未抵押時各收 60。

經過或停在起點領 200；城市稅付 100，城市補助領 100，公園沒有金錢效果。機遇卡共 12 張，洗勻依序抽取，抽完再洗。前進依規則領起點獎金、後退及拘留不領。

雙骰可再擲，額外行動不另計回合；同回合第三次雙骰直接入拘留所。普通停在拘留格只算探訪。被拘留可支付 50 後正常擲骰，或試擲雙骰；成功離開無額外擲骰，第三次失敗必付 50 後依原骰點移動。拘留期間仍可收租及在自己回合管理資產。

抵押收原價 50%，停止收租。一般土地全組無建築才可抵押。贖回付抵押金 110%，向上取整。現金及未抵押、全組無建築的土地可交換；對方接受才整筆完成，不能賒帳。

欠款時只可出售建築及抵押；籌足才付款。可變賣價值仍不足時才可破產。欠玩家時，現金、建築半價所得及土地移交，保留抵押狀態；欠銀行則土地恢復無主、未抵押、無建築。只剩一人即完局。

快速模式每人最多 20 回合，完成者仍可收租與拍賣。最後的待處理效果完成才結算。淨資產＝現金＋未抵押土地原價＋抵押土地原價 50%＋建築成本 50%。同分先比現金，再比完整地段數，仍相同並列；破產者排最後。經典模式直到只剩一人，沒有固定時間上限。

## 使用與儲存

直接開啟 GitHub Pages 網址。手機點格子看詳情；桌面主要操作在棋盤中央；手機操作區在棋盤下方，頂部保留目前玩家與現金。資產管理和交易按鈕在自己回合出現。棋盤上的棋子與建築以 WebGL 即時繪製 3D 模型（小船、樹苗、火箭、咖啡杯；小屋、樓宇、地標），有光影、逐格跳動及建築升級彈出效果；玩家卡、圖例、骰子及城市插圖使用同一批模型產生的 3D 縮圖。瀏覽器不支援 WebGL 時自動改用原有向量插畫。玩家卡與持有人標記以相同顏色對應。擲骰結果確定後先存檔，再呈現動畫；重新整理後按「繼續上次對局」。支援鍵盤 Tab、Enter、Escape，無拖曳操作。頂部「全螢幕」按鈕（或按 F）可切換全螢幕，Esc 離開；手提電腦及平板的棋盤按螢幕高度縮放，毋須捲動即可看到整個棋盤，iPad 直向時玩家資料移至棋盤下方。瀏覽器不支援全螢幕時（例如 iPhone）不顯示按鈕。勾選「加速」可略過等待，系統減少動態效果設定亦適用。

進度存在目前瀏覽器的 localStorage，只保留一局。不同裝置不會同步；清除網站資料會刪除進度。無法儲存時畫面會提示。不要用 file:// 開啟 ES module，需透過靜態 HTTP 伺服器。

## 維護

- `data.js`：28 格棋盤、6 組地段、售價、租金與 12 張事件卡。
- `engine.js`：純規則引擎、狀態驗證、固定種子亂數、電腦決策。`AI` 集中定義估值、現金保留與競投上限。
- `app.js`：畫面、動畫、操作、本機儲存。
- `board3d.js`：3D 模型、透明 WebGL 疊加層及縮圖；只讀取畫面上棋子／建築的位置，不改遊戲狀態。
- `vendor/three.min.js`：精簡打包的 three.js 0.187（MIT，授權見 `vendor/THREE-LICENSE`），由 `tools/three-entry.js` 產生，指令寫在該檔開頭。新增 three.js 元件時須重新打包。
- `style.css`：桌面、平板與手機介面。
- `tests/engine.test.js`：規則邊界及批次模擬，執行 `npm test`，不須安裝套件。
- `docs/TEST-RESULTS.md`：驗證範圍與限制。

GitHub Pages 使用 main 分支根目錄，`.nojekyll` 停用 Jekyll。遊戲本身沒有建置步驟。Google Fonts 無法載入時使用系統字型。測試可向 dispatch 傳入指定骰子，正式 UI 沒有固定骰子入口。

電腦通常保留 200，完成地段可保留 100。拍賣估值一般為原價 110%、完成地段 130%。會主動以原價加 200 尋求收購已持有地段的其他土地，每回合最多提出一次；使用相同公開估值判斷接受或拒絕，不讀取未來骰子或卡牌。經典模式可能長時間膠著，建議日常使用快速模式。

本作品參考置業桌遊核心機制；名稱、地名、卡牌文案與視覺均為原創，與 MONOPOLY 品牌無關。
