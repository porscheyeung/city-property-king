## 尚未驗證與限制

未在真實 iPad、iPhone、Safari 或其他實體觸控裝置測試；手機驗證為 Chromium 視窗尺寸模擬。未完成真人平衡試玩，不宣稱電腦強度、平均遊戲時間或各地段勝率已驗證。

經典模式可能膠著，建議預設快速模式。沒有網上連線、多裝置存檔同步或帳戶。清除瀏覽器資料會刪除本機進度。Google Fonts 需要網絡，失敗時使用系統字型。玩家可透過瀏覽器自行修改本機存檔，本作品沒有防作弊伺服器。
